# Changelog

## [0.1.0] - 2026-11-13
### Added
- Initial Smartify App Manager as an admin-only Home Assistant custom integration.
- Curated catalog of twelve existing Smartify repositories.
- Individual repository links for independent installation paths.
- Responsive sidebar panel with light/dark theme support.
- Administrator PIN creation/change; hashed persistence and failed-attempt cooldown.
- Per-module, PIN-guarded *catalog status* (not runtime enforcement).
- Project documentation, contributor rules and release notes.
### Not included
- No trial period, expiry, license backend or enforced runtime lock.
- No automated install/update or release-verification functions.
